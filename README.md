
# Adventure Works Sales Analysis Dashboard | Power BI

## 📊 Project Overview

Developed an interactive Power BI dashboard to analyze sales performance, order trends, profitability, product categories, and customer behavior. The dashboard transforms sales data into actionable business insights through KPI tracking and dynamic visualizations, enabling users to explore performance across product categories, warehouse regions, payment methods, shipping methods, brands, and order statuses.


![image Alt]()
## 🎯 Business Objectives

- Monitor overall sales, order volume, profit, and return rate.
- Identify top-performing product categories and brands.
- Analyze return rates across warehouse regions.
- Compare order distribution by payment method.
- Evaluate average delivery days by shipping method.
- Examine high-value orders and order amounts by status.
- Enable interactive analysis using slicers for product category, customer gender, and season.

## 📌 Key Performance Indicators (KPIs)

- Total Sales: $3.5M
- Total Orders: 8.68K
- High-Value Orders: 2K
- Total Profit: $668.3K
- Return Rate: 9.9%

## 📈 Dashboard Insights

- Product Category Performance: Electronics generates the highest sales among the displayed product categories.
- Regional Returns: The West and South regions have the highest displayed return rates at 10.6%.
- Payment Methods: PayPal, bank transfer, and credit card show approximately 1.5K orders each.
- High-Value Orders by Brand: Trendify leads the displayed brands with 248 high-value orders.
- Shipping Performance: Standard and pickup shipping show average delivery times of five days, while same-day shipping averages two days.
- Order Status Analysis: The dashboard compares order amounts across delivered, shipped, returned, processing, and cancelled orders.

Note: These observations reflect the values displayed in the dashboard and may change when interactive filters are applied.

## 🛠️ Tools & Technologies

- Power BI Desktop — Dashboard development and data visualization
- Power Query — Data preparation and transformation
- DAX — KPI calculations and analytical measures
- Data Visualization — Interactive charts, KPI cards, and slicers

## 🎨 Dashboard Features

- Interactive slicers for product category, customer gender, and season
- KPI cards for key business metrics
- Horizontal bar charts for category and brand comparisons
- Column charts for regional return rates and payment methods
- Shipping performance and order-status analysis
- A consistent dark-themed layout with green visual accents

## 💡 Business Value

This dashboard provides a consolidated view of sales and operational performance. It helps stakeholders identify leading product categories, monitor regional return patterns, compare payment preferences, and evaluate shipping performance to support data-driven business decisions.
